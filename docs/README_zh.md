# FIA 使用说明

FIA 表示 **Find—Inject—Attack**。当前流程为：

**干净类几何筛选 → 校验预先配置的攻击方向 → 构造触发器 → VLM代理评估 → 独立测试与多检查点评估。**

## 开始运行

1. 仓库根目录执行 `python -m pip install -e .`。
2. 按 [资产说明](ASSETS.md) 准备干净蒸馏分片、权重和评估图像。
3. 按 [运行步骤](REPRODUCING.md) 导出候选类对。
4. 按 [固定方向 Find](FIXED_DIRECTION_FIND.md) 校验配置方向属于候选池，再注入和评估。
5. 运行 `python examples/smoke_test.py` 可检查核心接口；它不验证攻击效果。

## 类对与方向

CIFAR-10的10类形成45个无向类对；已有几何结果保留26对，即52个有向候选。
鹿→飞机是CIFAR-10实验配置，不能套用到其他数据集。方向是配置输入，几何筛选校验资格；
固定方向的代理评估不声称找到全局或局部最优解。参数使用下、上分位点，CIFAR-10配置为0.30与0.90。

## 复现范围

三轮主实验与七检查点轨迹分别报告；延长训练继续使用同一含毒数据。
训练选择图像来自训练划分，最终测试图像来自独立测试划分。模型权重、数据和SWIFT运行程序需另行准备。
注入核心按正文采用分阶段 BN 状态和独立预处理路径，见 [实现配置](REPRODUCIBILITY.md)；
此次文档同步没有改动注入代码或实验数字，不把文档更新当作数值复现。
