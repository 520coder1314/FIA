# Implementation and evidence boundaries

This release is a revised core for new runs. It is not a claim of reproducing the
historical manuscript metrics. The historical scripts remain in the local research
workspace and are not included in this minimal repository.

| Component | Revised behavior |
|---|---|
| Pair choice | Quantile geometry filter; direction supplied by configuration and validated against the pool (see FIXED_DIRECTION_FIND.md) |
| Proxy state | Backbone parameters and BN running buffers frozen throughout head fitting |
| Preprocessing | One declared route for classification, mask construction and alignment |
| Mask | Gradient-derived channel gating; not standard Grad-CAM++ |
| Appearance | Explicit stop-gradient or differentiable mode; Gaussian-window SSIM implementation |
| Optimization | Bounded projected Adam, explicit schedule and best-iterate selection |
| Evidence | Run settings, input/checkpoint/code hashes, saved fitted proxy and trigger artifacts |

The quality modes match their declared gradient semantics, not the historical
skimage implementation numerically. Any claim about effectiveness, persistence or
appearance for this code needs measurements generated by this code.

## Validation performed

The unit-test suite covers frozen weights/buffers, appearance gradients, mask and trigger
bounds, unique pair counts, rejection of nonfinite distances, empirical-margin
selection, and disjoint evaluation splits with duplicate-content rejection.
A local real-weight smoke run used one head epoch and two injection steps; only one
selected item's label changed and nine untouched shards remained byte-identical.
This validates interfaces, not attack strength. A local CIFAR-10 geometry run exported
26/45 unordered pairs. The local clean shard identity is not established as the
historical main-experiment artifact, so that output is not published as a reproduction.

## Paper-level reproduction still requires

Exact clean/poisoned artifacts or a fully specified new distillation run; proxy and
victim checkpoints; downstream training/evaluation software versions and settings;
independent selection/test sets; matching candidate budgets/seeds; full clean-task
accuracy and paired clean/triggered measurements. These are external prerequisites,
not capabilities supplied by the smoke test.

## Current manuscript versus this core's injection profile

Documentation of fixed-direction Find matches the current manuscript workflow.
The public core keeps BN buffers frozen and uses one preprocessing route; the
manuscript describes shard states established during auxiliary-head fitting and
separate mask/classifier and feature-preprocessing paths. These are actual
implementation differences. A documentation update does not make them numerically
equivalent. Match the chosen profile to the run manifest before attributing results
to it. This synchronization changes documentation and artwork, not injection code
or archived experimental measurements.
